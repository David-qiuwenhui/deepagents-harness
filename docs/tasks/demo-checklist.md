# DeepAgents Agent Demo 演示清单

> 用于向团队和同事展示 Agent 能力的功能演示脚本。按顺序执行，逐步展示 Agent 的能力层次。

## 准备工作

```bash
# 1. 启动服务器
uv run uvicorn agent.server:app --host 0.0.0.0 --port 8000

# 2. 打开浏览器访问
# http://localhost:8000
```

---

## 第一部分：基础对话能力

> 展示 Agent 的基本理解和响应能力。

### 1.1 自由对话

**输入**：`你好，请介绍一下你自己`

**预期**：Agent 用中文自我介绍，提到自己是基于 GLM-5.1 的助手，拥有工具和记忆能力。

---

## 第二部分：工具调用（从简单到复杂）

> 展示 Agent 如何根据语义理解自动选择合适的工具。

### 2.1 时间查询

**输入**：`现在是几点？`

**预期**：
- Agent 调用 `get_current_time` 工具
- 蓝色工具卡片显示工具名和调用参数
- 绿色结果卡片显示返回的时间

**演示要点**：Agent 不需要"时间"关键词精确匹配，而是通过语义理解知道用户想查时间。

### 2.2 数学计算

**输入**：`帮我算一下 15 * 37 + 128 的结果`

**预期**：
- Agent 调用 `calculate` 工具
- 工具卡片和结果卡片正确展示
- 回答包含计算过程和结果（683）

**演示要点**：Agent 自动提取数学表达式，不需要用户用特定格式输入。

### 2.3 网络搜索

**输入**：`搜索一下最新的 AI Agent 框架有哪些`

**预期**：
- Agent 调用 `web_search` 工具
- 返回带有标题、来源链接、摘要的搜索结果
- Markdown 格式正确渲染（标题、列表、加粗等）

**演示要点**：
- 搜索结果是实时获取的，不是预置数据
- 对比普通 LLM 的知识截止日期限制，Agent 能获取最新信息
- Markdown 渲染让搜索结果可读性更高

### 2.4 文件操作（写入 + 列出 + 读取）

**步骤一**：`帮我在 workspace 里创建一个 todo.md 文件，内容写三件今天要做的事`

**预期**：
- Agent 调用 `write_file` 工具
- 自动生成有意义的 todo 内容并写入

**步骤二**：`看看 workspace 目录下有什么文件`

**预期**：
- Agent 调用 `list_directory` 工具
- 显示刚才创建的文件

**步骤三**：`读一下 workspace 里的文件内容`

**预期**：
- Agent 调用 `read_file` 工具
- 正确显示之前写入的内容

**演示要点**：
- 三个工具联动完成一个完整的工作流（创建 → 确认 → 读取）
- 所有文件操作限制在 sandbox 目录内，安全可控

### 2.5 组合调用

**输入**：`搜索一下今天的科技新闻，然后把前 3 条新闻的标题保存到 workspace/news.md 文件里`

**预期**：
- Agent 先调用 `web_search` 搜索新闻
- 再调用 `write_file` 保存结果
- 两个工具协同完成复杂任务

**演示要点**：Agent 能将一个复杂请求拆解为多个工具调用步骤，自动编排执行顺序。

---

## 第三部分：Markdown 渲染

> 展示 Agent 返回内容的富文本渲染能力。

### 3.1 综合格式展示

**输入**：`用 Markdown 格式给我展示一个包含标题、列表、表格、代码块和引用的示例`

**预期**：
- 标题（h1/h2/h3）使用 Poppins 字体，有层次感
- 列表正确缩进
- 表格有边框和表头背景
- 代码块深色背景 + 语法高亮
- 引用块有左侧边线

### 3.2 搜索结果的 Markdown 渲染

（已在 2.3 中覆盖，可一并讲解）

**演示要点**：
- 对比"纯文本 LLM 输出"和"Agent + Markdown 渲染"的体验差异
- 代码高亮让技术内容更易读
- 表格和列表让结构化信息更清晰

---

## 第四部分：长期记忆系统

> 展示 Agent 跨对话会话的记忆能力。

### 4.1 保存记忆

**输入**：`我叫文辉，我最喜欢的编程语言是 Python，记住这些信息`

**预期**：
- Agent 调用 `save_memory` 工具（紫色卡片）
- 确认信息已保存

### 4.2 回忆记忆（同一会话）

**输入**：`你还记得我叫什么名字吗？`

**预期**：
- Agent 调用 `recall_memory` 工具（紫色卡片）
- 正确回答"文辉"

### 4.3 跨会话记忆

**操作**：刷新浏览器页面（新会话）

**输入**：`我之前告诉过你我喜欢的编程语言是什么？`

**预期**：
- Agent 调用 `recall_memory` 工具
- 正确回答"Python"（证明记忆跨会话持久存在）

### 4.4 列出所有记忆

**输入**：`列出你记住的关于我的所有信息`

**预期**：
- Agent 调用 `list_memories` 工具
- 显示所有已保存的记忆条目，包含保存时间

**演示要点**：
- 紫色卡片区分记忆操作和普通工具调用
- 记忆是 Agent 主动管理的，不需要用户手动存储
- 刷新页面后记忆仍在（服务重启前有效）

---

## 第五部分：Inspector 调试面板

> 展示底层工作原理，帮助技术人员理解 Agent 的执行过程。

**操作**：点击右侧 Inspector 面板展开

**展示内容**：
- **Timeline**：事件时间线，每个 token / 工具调用都是一个小点
- **Stats**：token 数、工具调用次数等统计
- **Step-through**：可以逐步回放每个 SSE 事件
- **Protocol card**：展示原始 SSE 数据格式

**演示要点**：
- 可视化展示"Agent 不是一次性生成回答，而是逐步思考、调用工具、组合结果"
- Protocol card 展示 SSE 事件流格式，便于技术讨论
- 记忆操作在 Stats 中单独计数

## 演示节奏建议

| 顺序 | 内容 | 时长 | 核心信息 |
|------|------|------|---------|
| 1 | 基础对话 | 1 分钟 | Agent 能理解中文、自然对话 |
| 2 | 工具调用 | 5 分钟 | Agent 自动选择和组合工具 |
| 3 | Markdown 渲染 | 2 分钟 | 输出格式丰富、可读性强 |
| 4 | 长期记忆 | 3 分钟 | Agent 跨会话记住用户信息 |
| 5 | Inspector | 2 分钟 | 透明可观测，技术栈可解释 |

总计约 **13 分钟**。

## 已知限制（可主动提及）

- 记忆数据存储在内存中，服务器重启后丢失（后续可升级为持久化存储）
- 文件操作限制在 workspace 目录内（安全沙箱）
- 搜索质量依赖 Tavily API
- GLM-5.1 的推理链（reasoning_content）目前无法在前端展示（LangChain 限制）
